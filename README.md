# Farmacia — maquetas de interfaz

Maquetas navegables de un sistema POS y de administración para una farmacia en Chile.
**Solo diseño de interfaz**: datos ficticios, sin backend. Ninguna acción guarda información, emite documentos tributarios ni procesa pagos.

Pantallas: login, inicio, POS/caja, ventas, devoluciones, catálogo, inventario, transferencias, compras, recetas, caja y turnos, convenios, reportes y administración.

Generado con `python manage.py export_mockups <salida>` desde el proyecto Django (`apps/mockups`).
